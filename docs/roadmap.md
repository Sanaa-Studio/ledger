# Ledger Roadmap

## Phase 1: Backend Foundation

- Create Express server
- Initialize TypeScript and Node.js
- Add health-check endpoint
- Add environment configuration
- Add request validation
- Add centralized error handling
- Tests around the resulting behavior

## Phase 2: Accounts and Transactions API

- Create account endpoints
- Create transaction endpoints
- Add filtering and pagination
- Add unit and integration tests

## Phase 3: PostgreSQL

- Design relational schema
- Add Prisma
- Create migrations
- Replace in-memory storage
- Add database constraints and indexes

## Phase 4: Authentication

- Register users
- Log users in
- Protect routes
- Enforce resource ownership

## Phase 5: Frontend

- Build React interface
- Add account and transaction views
- Add forms and filters
- Add monthly dashboard

## Phase 6: Deployment

- Add Docker
- Add Docker Compose
- Add CI/CD
- Deploy to AWS
- Provision infrastructure with Terraform
