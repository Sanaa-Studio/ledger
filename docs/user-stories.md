# User Stories

## Accounts

- As a user, I want to create a financial account so that I can track money held in different places.
- As a user, I want to view all of my accounts so that I can understand where my money is stored.
- As a user, I want to update an account so that I can correct its name or type.
- As a user, I want to delete an unused account when it has no dependent transactions.

## Transactions

- As a user, I want to record an income transaction so that I can track money received.
- As a user, I want to record an expense transaction so that I can track money spent.
- As a user, I want to categorize a transaction so that I can understand my spending.
- As a user, I want to edit a transaction so that I can correct mistakes.
- As a user, I want to delete a transaction so that incorrect records do not affect my reports.
- As a user, I want to filter transactions by date, account, category, and type.
